# Лабораторная работа 1

## Структура файлов данных

- `movies.csv` — информация о фильмах (movieId, title, genres).
- `ratings.csv` — оценки пользователей (userId, movieId, rating, timestamp).
- `tags.csv` — теги, присвоенные пользователями фильмам.
- `genres.txt` — список жанров.
- `occupation.txt` — список профессий пользователей.
- `users.txt` — информация о пользователях.

## Результаты работы

- `ratings_count.txt` — минимальный и максимальный идентификаторы пользователей
  из `ratings.csv` и количество строк с этими идентификаторами.
- `sqlite.txt` — версия установленной СУБД SQLite и режимы вывода данных,
  доступные в утилите `sqlite3`.
- `script.py` — скрипт на Python для подсчёта количества записей по пользователям.
